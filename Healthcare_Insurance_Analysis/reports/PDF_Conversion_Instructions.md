# 📄 How to Convert HTML Report to PDF

## Quick Instructions

Your professional healthcare insurance analysis presentation is ready! Follow these simple steps to create a PDF version for your client/manager presentation:

### Method 1: Using Web Browser (Recommended)
1. **Open the HTML file:**
   - Navigate to: `reports/Healthcare_Insurance_Executive_Report.html`
   - Double-click to open in your default browser (Chrome, Firefox, Edge, Safari)

2. **Print to PDF:**
   - Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
   - In the print dialog, select **"Save as PDF"** or **"Microsoft Print to PDF"**
   
3. **Optimize Settings:**
   - Set **Margins** to "Minimum" or "None"
   - Enable **"Background graphics"** for colors and styling
   - Choose **Paper size: A4** or **Letter**
   - Set **Scale** to 100% or "Fit to page width"

4. **Save:**
   - Click **"Save"** or **"Print"**
   - Choose location: `reports/Healthcare_Insurance_Executive_Presentation.pdf`

### Method 2: Using Online Converters
- Upload HTML file to: HTML2PDF.com, SmallPDF, or ILovePDF
- Download the converted PDF

### Method 3: Using Microsoft Edge (Windows)
1. Open HTML file in Edge
2. Click **"..."** menu → **"Print"**
3. Select **"Save as PDF"**
4. Click **"Save"**
